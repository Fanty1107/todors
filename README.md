## Todo — Task Manager

```bash
Usage:
  todo <cmd>

Cmd:
  add     Add a task
  rm      Remove a task by title
  up      Update a task by title
  show    Show all tasks
  h       Show this message

Avaible Status:
  Uncompleted
  Starting
  Completed

Exemples:
  todo add
  todo rm
  todo up
  todo show"
  ```
